# Документация SDK

[English](../en/README.md) · [Репозиторий](../../README.ru.md)

SDK предназначен для TypeScript-плагинов десктопного приложения Sobes. Пакет содержит манифест и собранный код; хост предоставляет API, запускает обработчики и размещает интерфейс.

| Раздел | Содержимое |

| [Основной API хоста](api.md) | Хранилище, встречи, скриншоты, навигация и управление оверлеем |

Текущий контракт: `apiVersion: 1`, `protocolVersion: 1`. Версии SDK и самого плагина независимы от версии API.

[Методы приложения](platform/README.md) проверяют права на конкретные ресурсы и поля в дополнение к основным разрешениям. Начните с этого раздела, если плагину нужны данные аккаунта или обновления по событиям. Для получения ответа модели [отправляйте запросы провайдеру](model-requests.md), используя собственные настройки плагина.

Исходные объявления: [типы](../../src/index.ts), [разрешения](../../src/permissions.json), [React](../../src/react.tsx), [API приложения](../../src/platform/types.ts).
