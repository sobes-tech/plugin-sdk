# Манифест и разрешения

[Документация](README.md) | [English](../en/manifest-and-permissions.md)

`PluginManifest` задаёт идентификатор плагина, интерфейсы, команды, события, настройки и запрашиваемые разрешения. Манифест находится в `PluginPackage.manifest`. Хост проверяет его перед установкой; неизвестные поля и неподдерживаемая версия API отклоняются.

## Поля

| Поле | Обязательно | Допустимое значение |
| --- | --- | --- |
| `id` | Да | Постоянный идентификатор плагина. Правила приведены ниже. |
| `version` | Да | Семантическая версия, например `1.0.0`. Увеличивайте её при выпуске обновления. |
| `apiVersion` | Да | Число `1`. |
| `name`, `description` | Да | Локализованный текст: `{ en: string, ru: string }`. Каждая строка непустая, не состоит из пробелов и занимает не более 1 000 байт UTF-8. |
| `permissions` | Да | Массив разрешений из таблицы ниже. Повторы и неизвестные разрешения запрещены. |
| `commands` | Да | До 64 команд. Если команд нет, укажите `[]`. |
| `views` | Нет | До 64 представлений. |
| `events` | Нет | Массив поддерживаемых событий жизненного цикла. Требует `events.subscribe`. См. [выполнение и сборку](runtime-and-build.md). |
| `settings` | Нет | До 64 настроек. |
| `networkDomains` | Нет | До 32 имён хостов или масок в нижнем регистре, каждая запись не длиннее 253 байт. Поддерживаются `*` и `*.example.com`; схема, порт и путь не указываются. См. [доступ к сети](network.md#разрешить-домены). |
| `requiredFeatures` | Нет | Возможности, необходимые плагину. Если хост не поддерживает хотя бы одну, установка отклоняется. См. [API приложения](platform/README.md). |
| `grants` | Нет | Запросы на операции, области доступа и поля ресурсов. Пользователь подтверждает фактические права при установке. |

В манифесте должна быть хотя бы одна команда, один элемент `views` или одно событие. Неизвестное поле или другая версия API приведут к отказу при проверке пакета.

### Идентификаторы и подписи

`id` связывает установку плагина с обновлениями и сохранёнными данными. Изменение `id` создаёт отдельный плагин. Отображаемое `name` не влияет на идентификацию.

ID плагина, команды, интерфейса и настройки состоит из 1–100 символов ASCII: строчных латинских букв, цифр, `-` и `.`. Первый символ — буква или цифра. Последовательность `..` и точка в конце запрещены. ID команд, интерфейсов и настроек должны быть уникальны внутри соответствующего списка.

`LocalizedText` имеет форму `{ en: string; ru: string }`. Обе строки обязательны, не могут состоять только из пробелов и ограничены 1 000 байт UTF-8 каждая. Хост выбирает соответствующую строку; автоматического перевода нет.

`localized(text: LocalizedText, locale: string): string` возвращает `text.ru`, если `locale` без учёта регистра начинается с `ru`, включая `ru-RU`. Для остальных значений возвращается `text.en`. Функция не проверяет содержимое.

### Команды

Форма: `{ id: string; title: LocalizedText; location: "meeting" | "settings" }`.

`id` должен совпадать с ключом обработчика в `definePlugin({ commands: ... })`. Команда `meeting` может получить снимок выбранной встречи; для чтения через `ctx.meeting.getSelected()` нужно `meeting.read` или `meetings.read`. Команда `settings` не получает снимок выбранной встречи. Методы чтения данных аккаунта, например `meetings.get`, проверяют собственные разрешения.

### Экраны и элементы интерфейса

Форма: `{ id, title, slot, order?, renderer?, icon?, showInSidebar?, display?, inlineWidth? }`. `slot` должен входить в список [UI-слотов](ui-slots.md). Неизвестные слоты отклоняются.

`renderer: "react"` требует UI-бандл, собранный из `uiEntrypoint`. Без `renderer` хост ожидает результат обработчика `definePlugin({ views: ... })`. Слоты оверлея требуют React. `id` должен совпадать с ключом зарегистрированного компонента или обработчика.

`display?: "popover" | "inline"` допускается только для `overlay.toolbar`, `overlay.panel`, `overlay.footer`, `overlay.message.header` и `overlay.message.footer`. Без этого поля сохраняется кнопка открытия popup; то же поведение задаёт `display: "popover"`. При `display: "inline"` сам React-интерфейс занимает место элемента в нативной строке, без popup и отдельной кнопки хоста. `overlay.workspace` и все слоты вне оверлея отклоняют `display`, в том числе `"popover"`.

`inlineWidth?: number` допускается только вместе с `display: "inline"`: целое число от 24 до 240 CSS-пикселей. Если ширина не указана, хост использует 36 px для панели инструментов и строки ввода, 24 px для элементов сообщения. Высоту фиксирует хост по высоте элементов строки. Эти поля не дают доступа к API: представлению по-прежнему нужно `overlay.render`, а действиям — соответствующие разрешения или гранты. Размеры и обработчики React описаны в разделе [встроенные элементы оверлея](react-ui.md#встроенные-элементы-оверлея).

`order` — знаковое 32-битное целое, по умолчанию `0`. Элементы одного слота сортируются по возрастанию. `showInSidebar` управляет пунктом навигации для `app.page`; `false` скрывает его. Страница остаётся доступна через `app.openPage`.

`icon` принимает имя иконки хоста, а не SVG или URL изображения: `layout-dashboard`, `file-text`, `calendar`, `image`, `notebook`, `chart`, `code`, `puzzle`, `settings`, `globe`, `search`, `list`, `folder`, `message`, `sparkles`, `kanban`, `terminal`, `book`, `bolt`, `star`.

### Настройки пользователя

```ts
import type { LocalizedText } from "@sobes-tech/plugin-sdk";

interface PluginSetting {
  id: string;
  title: LocalizedText;
  default: string | boolean;
  inputType?: "text" | "url" | "password";
}
```

`settings` описывает значения, редактируемые на странице установленного плагина. Boolean в `default` создаёт переключатель, строка — текстовое поле. Строковое значение ограничено 2 000 байт UTF-8. Значения передаются в `ctx.settings` и `usePlugin().settings`.

`inputType` применяется только к строковым настройкам: обычный текст, URL или поле со скрытыми символами. Boolean с `inputType` отклоняется. Тип `password` только скрывает ввод на экране: настройки хранятся в локальном JSON, без шифрования. Не включайте реальные ключи в значения по умолчанию.

Изменение настроек отзывает активные выполнения и токены интерфейсов. React-компонент может быть создан заново с новыми значениями. Постоянные данные хранятся через [storage или files](api.md#хранилище), отдельно от состояния компонента.

## Справочник разрешений

Разрешение проверяется для каждого метода. Чтение и запись независимы. При установке пользователь подтверждает список разрешений конкретного пакета; при обновлении он заменяется списком нового манифеста.

| Разрешение | Область | Что разрешает |
| --- | --- | --- |
| `meeting.read` | Выбранная встреча | Worker-хелпер `meeting.getSelected()`. |
| `meetings.read` | Текущий аккаунт | `meetings.list`, `meetings.get`, `meetings.messages`, а также переданный worker снимок встречи. |
| `meetings.write` | Текущий аккаунт | `meetings.create`, `meetings.rename`. |
| `screenshots.read` | Текущий аккаунт | `screenshots.list`, `screenshots.get`. |
| `notes.read` | Текущий аккаунт | `notes.list`, `notes.get`, `notes.folders`. |
| `notes.write` | Текущий аккаунт | `notes.create`, `notes.update`. |
| `tracker.read` | Текущий аккаунт | `tracker.columns`, `tracker.cards`, `tracker.get`. |
| `tracker.write` | Текущий аккаунт | `tracker.create`, `tracker.update`. |
| `models.read` | Приложение | `models.list`. Не даёт права на генерацию. |
| `clipboard.write` | Устройство | `clipboard.writeText`. Чтения буфера обмена нет. |
| `app.navigate` | Приложение | `app.navigate`, `app.openPage`. |
| `app.openExternal` | Устройство | `app.openExternal`. |
| `notifications.show` | Приложение | `notifications.show`. |
| `events.subscribe` | Текущий аккаунт | Объявленные обработчики жизненного цикла worker. Для [потока событий ресурсов](platform/events.md) нужны права на ресурсы. |
| `network.request` | Заявленные домены | `network.request` в пределах `networkDomains`. |
| `ui.render` | Заявленные слоты приложения | Представления вне оверлея и интерфейс, возвращаемый worker. |
| `overlay.render` | Заявленные слоты оверлея | React-представления в оверлее встречи. |
| `overlay.read` | Активный оверлей | `overlay.context`. |
| `overlay.control` | Активный оверлей | `overlay.setDraft`, `overlay.insertText`. |
| `files.export` | Выбранное пользователем место | Worker-хелпер `files.exportText`. |
| `files.userSelected` | Выбранный JSON-файл | `files.openJson`, `files.saveJson`. Каждый вызов открывает системный диалог. |
| `plugin.storage` | Установка плагина и аккаунт | `storage.get`, `storage.set`, `storage.remove`. Неявное разрешение. |
| `plugin.files` | Установка плагина и аккаунт | `files.readJson`, `files.writeJson`, `files.list`. Неявное разрешение. |
| `api.inspect` | Приложение | `api.capabilities`. Неявное разрешение. |

`plugin.storage`, `plugin.files` и `api.inspect` действуют неявно, без записи в `permissions`. Они предоставляют собственное хранилище плагина и сведения о хосте, но не доступ к данным аккаунта или полю ввода оверлея.

Для `network.request` также нужен `networkDomains`. Точное имя разрешает только этот хост. `*.example.com` разрешает один или несколько уровней поддоменов, например `api.example.com` и `v2.api.example.com`, но не сам `example.com`. Запись `*` разрешает любой публичный HTTPS-адрес. Проверка частных IP продолжает действовать; адрес каждого перенаправления проверяется заново.

Части DNS-имени разделяются точками, состоят из строчных латинских букв, цифр и дефиса и имеют длину до 63 символов. Дефис в начале или конце части запрещён; международные имена записываются в punycode. Схема, путь, порт, пустые части и частичные маски вроде `api.*.com` недопустимы. После `*.` нужны хотя бы две части, поэтому `*.com` не принимается. При изменении списка в обновлении пользователь заново подтверждает доступ.

### Как прочитать реестр разрешений

Экспортируемый массив `permissions` содержит следующие поля каждой записи:

| Поле | Содержимое |
| --- | --- |
| `id` | Идентификатор разрешения. |
| `title` | `LocalizedText` с отображаемым названием. |
| `scope` | Название области, например `account`, `plugin` или `declaredDomains`. |
| `risk` | `read`, `write`, `render` или `network`. |
| `methods` | Имена RPC-методов, доступных с этим разрешением. Для локальных хелперов и элементов интерфейса массив может быть пустым. |
| `implicit` | Доступно ли разрешение без запроса в манифесте. |

Это метаданные. Изменение массива в коде плагина не меняет доступ: нативный хост использует собственный реестр.

## Проверка доступа

Хост получает аккаунт из авторизованной сессии приложения. Параметры плагина не могут выбрать другой аккаунт. Установка, ревизия пакета и разрешение проверяются перед вызовом и перед выдачей результата.

Отключение, обновление и удаление плагина отзывают активные выполнения. Изменение настроек или сессии тоже может их отозвать. Поздний результат отклоняется, но уже отправленная на сервер запись не отменяется. См. [ошибки и повторные запросы](api.md#ошибки-и-повторные-запросы).

Основные разрешения действуют для соответствующих данных текущего аккаунта. [API приложения](platform/README.md) отдельно проверяет права на конкретные ресурсы, операции и поля.
