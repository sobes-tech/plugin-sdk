# Запросы к моделям

[Документация](README.md) · [English](../en/model-requests.md)

Плагин обращается к своему провайдеру через [`createPluginFetch`](network.md). Он передаёт URL, API-ключ, модель и тело запроса. SDK не предоставляет плагинам ключи, выбор провайдера или сервис генерации.

## Настройки провайдера

Объявите поля в манифесте и читайте их через `usePlugin().settings`:

```ts
settings: [
  { id: "endpoint", title: { en: "API URL", ru: "URL API" }, default: "https://api.openai.com/v1", inputType: "url" },
  { id: "apiKey", title: { en: "API key", ru: "API-ключ" }, default: "", inputType: "password" },
  { id: "model", title: { en: "Model ID", ru: "ID модели" }, default: "gpt-4.1-mini" },
],
permissions: ["ui.render", "network.request"],
networkDomains: ["*"],
```

`password` скрывает символы в поле ввода. Настройки хранятся в локальном JSON без шифрования; это поле не является защищённым хранилищем. Реальные ключи не должны попадать в исходники, значения по умолчанию, логи и URL запросов.

Здесь `networkDomains: ["*"]` позволяет пользователю выбрать любой публичный HTTPS-провайдер через настройку URL. Если плагин работает с определёнными серверами, укажите точные имена или маску поддоменов вроде `*.example.com`. Пользователь подтверждает заявленный доступ; значение настройки не может его расширить. Частные и локальные IP остаются закрыты даже с `*`.

## HTTP или библиотека провайдера

Полученную функцию можно вызывать как обычный fetch или передать библиотеке с поддержкой собственного fetch. Например, `@ai-sdk/openai` принимает её при создании провайдера:

```ts
const provider = createOpenAI({
  apiKey: String(plugin.settings.apiKey),
  baseURL: String(plugin.settings.endpoint),
  fetch: createPluginFetch(plugin.api),
});
const model = provider(String(plugin.settings.model));
```

Здесь `plugin` получен из `usePlugin()`, `createOpenAI` импортирован из `@ai-sdk/openai`, а `createPluginFetch` — из `@sobes-tech/plugin-sdk`. Библиотеку провайдера нужно включить в сборку. ID модели берётся из настроек плагина и не связан с каталогом моделей Sobes.

Формат запроса, ответ и лимит токенов определяет провайдер. На передачу данных действуют [сетевые ограничения](network.md#лимиты-и-отличия-от-браузера). `AbortSignal` закрывает соединение, но не отменяет оплату уже принятого провайдером запроса. Повтор после ошибки может запустить ещё одну генерацию, поэтому решение о повторе принимает плагин.

## Готовый пример

[Разбор кода](../../examples/code-explainer/README.md) отправляет chat-completions запрос со своими настройками, постепенно читает SSE, показывает Markdown и отменяет запрос при закрытии страницы. При остановке полученный текст остаётся на экране. Это пример SDK; в маркетплейсе его нет.

У [контроллера запроса](../../examples/code-explainer/generation.ts) нет серверного ID операции и метода восстановления. Продолжить закрытое соединение можно только тогда, когда такую возможность предоставляет выбранный провайдер.
