# HTTP и fetch

[Документация](README.md) · [English](../en/network.md)

`createPluginFetch` нужен для библиотек, которые принимают свой `fetch`, а также для потоковых и бинарных ответов. Запрос выполняет нативный хост, а плагин получает обычный браузерный `Response`. Перед соединением хост проверяет разрешения плагина.

Для небольшого текстового запроса из worker проще использовать [`network.request`](api.md#сетевые-запросы). Он целиком загружает ответ и ограничивает запрос 15 секундами.

## Разрешить домены

Добавьте `"network.request"` в `permissions`, а разрешённые адреса — в `networkDomains`:

```ts
permissions: ["ui.render", "network.request"],
networkDomains: ["api.openai.com"],
```

Запись может быть точным именем или маской:

| Запись | Что разрешает |
| --- | --- |
| `api.example.com` | Только этот хост |
| `*.example.com` | `api.example.com`, `v2.api.example.com` и остальные поддомены; сам `example.com` не входит |
| `*` | Любой публичный HTTPS-адрес |

Пользователь подтверждает указанный доступ при установке или обновлении пакета. Адрес каждого перенаправления тоже должен подходить под запись. Маски не отключают HTTPS, порт 443, проверку DNS и запрет частных, локальных и других непубличных IP-адресов.

Имена хостов и часть после `*.` записываются строчными ASCII-символами или в punycode: хотя бы две непустые части длиной до 63 символов каждая. Дефис в начале и конце части запрещён. Вся запись ограничена 253 байтами; схема, путь, порт и частичные маски вроде `api.*.com` не принимаются. Запись `*.com` тоже недопустима.

## Подключить адаптер

```ts
import { createPluginFetch } from "@sobes-tech/plugin-sdk";
import { usePlugin } from "@sobes-tech/plugin-sdk/react";

function useProviderFetch() {
  const plugin = usePlugin();

  return createPluginFetch(plugin.api);
}
```

Сигнатура: `createPluginFetch(call): PluginFetch`. Аргумент `call` — функция `api` из контекста плагина. Полученный `PluginFetch` принимает `(input: RequestInfo | URL, init?: RequestInit)` и возвращает `Promise<Response>`.

Передайте его в настройку библиотеки, которая заменяет `fetch`. Например, для `@ai-sdk/openai`:

```ts
const provider = createOpenAI({
  apiKey: String(plugin.settings.apiKey),
  baseURL: String(plugin.settings.endpoint),
  fetch: createPluginFetch(plugin.api),
});
```

`createOpenAI` импортируется из `@ai-sdk/openai`. URL, API-ключ и модель задаются в настройках вашего плагина. Библиотеку провайдера включите в сборку: загрузка модулей с CDN во время работы запрещена. Полный пример — в разделе [запросов к моделям](model-requests.md). Запрос идёт с компьютера пользователя к выбранному провайдеру. Ошибки, повторы, потоковый ответ и сохранение переписки обрабатывает сам плагин.

## Читать ответ и отменять запрос

У ответа доступны `status`, `ok`, `headers`, `url`, `redirected`, методы `text()`, `json()`, `arrayBuffer()` и `body` типа `ReadableStream<Uint8Array>`. Promise завершается после получения заголовков. Код 401 или 429 тоже возвращается как ответ; проверяйте `response.ok`.

Передайте `AbortSignal` в `init.signal`, чтобы отменить соединение или чтение тела. Вызов `response.body.cancel()` тоже закрывает нативный запрос. Каждое тело нужно прочитать или отменить: непрочитанный ответ занимает слот до истечения срока. Если ошибка возникла после получения заголовков, она придёт при чтении тела.

Хост останавливает запросы при отключении или удалении плагина, отзыве прав, замене пакета, закрытии его интерфейса и выходе из аккаунта. Отменённый запрос мог уже дойти до провайдера и стать платным. Повторяйте его только тогда, когда повтор допустим для самой операции.

## Лимиты и отличия от браузера

| Параметр | Поведение |
| --- | --- |
| Среда | React-интерфейс с браузерными `Request`, `Response` и `ReadableStream`; в QuickJS worker этих объектов нет |
| Методы | GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS |
| Тело запроса | До 2 МиБ; целиком собирается перед отправкой, потоковая загрузка не поддерживается |
| Тело ответа | До 16 МиБ; приходит частями не больше 128 КиБ |
| Заголовки | До 32 заголовков запроса, суммарно 64 КиБ; значение до 8 КиБ |
| Одновременные запросы | 8 на установку, 64 на весь хост |
| Время | 10 минут на соединение и передачу тела; на установку соединения — 10 секунд |
| Перенаправления | По умолчанию `follow`, максимум три; поддерживаются `manual` и `error` |
| Адрес | HTTPS, порт 443, только публичные IP; логин и пароль в URL запрещены |

Хост закрепляет проверенные DNS-адреса за соединением и проверяет каждый переход. При перенаправлении на другой origin он убирает `Authorization`. POST меняется на GET для 301/302; код 303 меняет метод на GET, кроме HEAD. Браузерный CORS на нативное соединение не распространяется.

Cookie jar и унаследованной авторизации аккаунта нет. Параметры `credentials`, `cache`, `mode`, `referrer`, `integrity` и другие браузерные настройки `RequestInit` не управляют нативным клиентом. При необходимости передайте свой заголовок `Authorization`. Заголовки `Cookie`, `Host`, `Proxy-Authorization`, `Connection`, `Transfer-Encoding` и `Content-Length` запрещены, а `Set-Cookie` исключается из ответа. Системный прокси и прокси приложения не используются. Прямые соединения через `window.fetch`, WebSocket и EventSource в iframe остаются закрыты.

Адаптер вызывает три внутренних RPC под одним разрешением `network.request`: `network.open`, `network.read` и `network.close`. Используйте адаптер: он управляет идентификаторами запросов, кодированием бинарных данных, отменой и освобождением ресурсов.
