# Среда выполнения и сборка

[Документация](README.md) | [English](../en/runtime-and-build.md)

Хост — десктопное приложение Sobes. Он проверяет пакет и разрешения, запускает обработчики и предоставляет API. Пакет может содержать worker, React-интерфейс или оба варианта.

## Модели выполнения

| Свойство | Worker | React |
| --- | --- | --- |
| Регистрация | `definePlugin(definition)` | `renderPlugin(views)` |
| Точка входа сборки | `entrypoint` | `uiEntrypoint` |
| Среда | Отдельный процесс QuickJS на вызов | Изолированный iframe |
| DOM | Нет | Есть |
| Состояние JS | Сбрасывается после вызова | Сохраняется до размонтирования iframe |
| Интерфейс | Возвращаемые `PluginView` / `PluginBlock` | React-компоненты |
| Оверлей | Не поддерживается | Поддерживается |
| Дополнительные методы | `meeting.getSelected`, `files.exportText` | Нет |

Глобальные переменные worker не сохраняются между вызовами. Постоянные данные хранятся через `storage` или `files`. Состояние React теряется при уничтожении iframe; скрытие уже открытой панели само по себе может сохранять компонент.

## Регистрация worker

Сигнатура: `definePlugin(definition: PluginDefinition): void`.

`PluginDefinition` содержит необязательные поля `commands` и `views` типа `Record<string, PluginHandler>`, а также `events` типа `Partial<Record<PluginEvent, PluginHandler>>`.

`PluginHandler` принимает `PluginContext` и возвращает `PluginView | PluginBlock | void` либо `Promise` того же результата. ID обработчиков команд и интерфейсов должны совпадать с объявлениями манифеста.

```ts
import { definePlugin } from "@sobes-tech/plugin-sdk";

definePlugin({
  commands: {
    status: ctx => ({
      title: "Status",
      blocks: [{ type: "text", text: ctx.locale }],
    }),
  },
});
```

Вне worker-хоста `definePlugin` выбрасывает ошибку `Plugin bundles must run inside Sobes`. Сериализованный UI описан в [UI-слотах](ui-slots.md#сериализованный-ui).

### Контекст вызова

| Поле | Тип | Значение |
| --- | --- | --- |
| `locale` | `"en" \| "ru"` | Язык текущего вызова |
| `settings` | `Readonly<Record<string, string \| boolean>>` | Сохранённые настройки манифеста |
| `input` | `JsonValue` | Параметры команды, действия или события |
| `state` | `JsonObject` | Состояние сериализованного интерфейса, переданное в вызов |
| `context` | `JsonObject` | Контекст места размещения или вызова |

Методы контекста перечислены в [API хоста](api.md). Результат `PluginView.state` передаётся следующему действию сериализованного интерфейса; это не сохраняемый JS-контекст процесса.

## Сборщик

Сигнатура: `buildPlugin(options): Promise<void>` из `@sobes-tech/plugin-sdk/build`. Выполняется в Bun.

| Поле | Значение |
| --- | --- |
| `manifest` | Объект `PluginManifest` |
| `entrypoint` | Путь к исходнику worker; необязателен, если есть React |
| `uiEntrypoint` | Путь к исходнику React; необязателен, если есть worker |
| `outfile` | Путь к итоговому JSON-файлу |

Требуется хотя бы одна точка входа. Если указаны обе, worker и React включаются в один пакет.

```ts
import { buildPlugin } from "@sobes-tech/plugin-sdk/build";
import type { PluginManifest } from "@sobes-tech/plugin-sdk";

export async function build(manifest: PluginManifest) {
  await buildPlugin({
    manifest,
    entrypoint: "./src/worker.ts",
    uiEntrypoint: "./src/ui.tsx",
    outfile: "./plugin.json",
  });
}
```

Формат результата — `PluginPackage`: `{ manifest, source, ui? }`. Поле `source` содержит worker JavaScript; при отсутствии worker его значение равно `"void 0"`. Поле `ui` имеет форму `{ javascript: string; css?: string }`.

Сборщик создаёт минифицированный browser-targeted IIFE без source map и отдельных чанков. Зависимости включаются в бандл. Runtime imports, Node-only библиотеки и загрузка внешнего кода в sandbox не поддерживаются. Ресурсы должны быть встроены как data URL; WOFF2-шрифты KaTeX встраиваются сборщиком.

По метаданным сборки Bun сборщик находит файлы `LICENSE`, `LICENCE`, `COPYING`, `NOTICE`, `COPYRIGHT` и `OFL` в корне зависимостей, чей код или CSS вошёл в бандл, включая имена с расширениями. Их тексты и заявленные метаданные пакетов сохраняются в неисполняемом комментарии в начале JavaScript worker или React. Порядок уведомлений детерминирован; их байты учитываются в лимите пакета. Нужен Bun 1.3.14 или новее с поддержкой metafile.

Если установленная зависимость не содержит файла уведомления, сборщик выводит предупреждение и отмечает её в комментарии. Перед распространением получите исходные уведомления у автора зависимости. Сборщик не скачивает и не придумывает лицензии, не предоставляет лицензию на плагин или SDK, не проверяет отдельно скопированные ресурсы и не подтверждает выполнение всех лицензионных условий. Автор проверяет отсутствующие уведомления, лицензии ресурсов и требования к исходному коду и распространению.

Лимит пакета — **32 MiB для полного UTF-8 JSON**, включая манифест, код, CSS, встроенные ресурсы и форматирование. Сборщик проверяет конечный размер перед записью. Установка JSON не запускает Bun, пакетный менеджер или lifecycle-скрипты зависимостей.

## События

Подписка объявляется в `manifest.events` и требует `events.subscribe`. Ключ в `definePlugin({events})` должен совпадать с именем события.

| Событие | Когда приходит | `input` |
| --- | --- | --- |
| `app.ready` | Включённый пакет готов к работе в текущей сессии | `{}` |
| `app.routeChanged` | Изменился маршрут главного окна | `{path}` |
| `app.themeChanged` | Изменилась тема главного документа | `{dark: boolean}` |
| `meeting.opened` | Главное окно открыло просмотр встречи | `{meetingId}` |
| `meeting.closed` | Главное окно закрыло или сменило просмотр встречи | `{meetingId}` |
| `meeting.updated` | Обновились данные запроса деталей или просмотра встречи | `{meetingId}` |
| `notes.changed` | Пришло уведомление о заметках или обновился их запрос | `{}` |
| `tracker.changed` | Обновился запрос трекера | `{}` |

```ts
import { definePlugin } from "@sobes-tech/plugin-sdk";

definePlugin({
  events: {
    "app.routeChanged": async ctx => {
      await ctx.storage.set("activeRoute", ctx.input);
    },
  },
});
```

Каждая доставка создаёт новый worker. `app.ready` учитывается по сессии и digest пакета; отключение и включение того же digest не гарантирует повторную доставку. `meeting.opened` и `meeting.closed` связаны с маршрутом главного окна.

События отражают изменения UI и запросов данных. Повторы возможны; доставка каждого промежуточного изменения не гарантируется. Постоянного журнала и курсора подтверждений нет. Для подписок на ресурсы со снимками и курсорами используйте [поток событий API приложения](platform/events.md).

## Ограничения выполнения

| Ограничение | Значение |
| --- | --- |
| Время одного worker | 60 секунд |
| Непрерывное выполнение QuickJS | 2 секунды; после завершённого RPC окно отсчитывается заново |
| Куча / стек QuickJS | 96 MiB / 512 KiB |
| Одновременные worker | Один на плагин, не больше четырёх на сессию |
| Очередь главного окна | До 32 вызовов на плагин |
| RPC из worker | До 64 за запуск; до 20 секунд на вызов в пределах общего дедлайна |
| Данные вызова | 8 MiB, отдельно от размера пакета |
| Ответ worker и результат API | 16 MiB |
| Открытые React-интерфейсы | До 64 разрешений на работу интерфейса на сессию |
| RPC из React | До восьми одновременных вызовов на интерфейс; параметры до 8 MiB, ответ до 16 MiB |
| Ожидание ответа в React | Обычно 20 секунд у хоста и 22 секунды в мосте SDK |
| Ожидание выбора JSON-файла | 300 секунд у хоста и 302 секунды в мосте SDK |

На границе процессов RPC worker выполняется синхронно, несмотря на `Promise` в SDK. Завершение RPC обновляет окно прерывания QuickJS, но не продлевает общий дедлайн 60 секунд.

`View lease` — временный токен API одного React-интерфейса. Закрытие интерфейса, смена настроек, обновление или отключение плагина и смена сессии отзывают токен и активные вызовы. Поздний ответ отклоняется. Запись, выполненная сервером до отзыва, не отменяется.

## Изоляция

Iframe использует непрозрачный origin. Доступ к DOM родителя, учётным данным приложения и Tauri IPC закрыт. CSP блокирует прямую сеть, внешние скрипты, шрифты и изображения, вложенные фреймы и отправку форм. Браузерные разрешения камеры, микрофона, геолокации, буфера обмена и захвата экрана отключены.

У worker отсутствуют DOM, Node.js, Bun, прямой файловый доступ и Tauri API. Данные, сеть и файлы доступны через API хоста с [проверкой разрешений](manifest-and-permissions.md).

### Изоляция сбоев

У каждого интерфейса своя граница ошибок. Необработанная ошибка скрипта, необработанное отклонение promise или отсутствие сигнала готовности за 15 секунд закрывают соответствующий iframe и его lease. Повторный запуск создаёт новый экземпляр.

Пакеты, настройки и хранилища установок проверяются отдельно. Ошибочная установка возвращается с `enabled: false` и `PluginInstallation.error`. Её запись и файлы сохраняются. Нечитаемый общий профиль блокирует открытие сессии.

Исключение, таймаут или выход worker завершают его вызов. Диалог сохранения после завершения worker не занимает один из четырёх рабочих слотов. Автоматически повторяется только отказ допуска `plugin_busy`, не дольше 65 секунд. Ошибки с неопределённым результатом операции автоматически не повторяются.

При доставке событий изменения ресурсов и автоматическом обновлении сериализованного UI учитывается цепочка вызвавших изменение плагинов. Участники цепочки исключаются из повторной обработки; разные ресурсы учитываются отдельно.

Iframe не гарантирует отдельный процесс ОС. Блокировка или авария общего браузерного движка находится за пределами этой изоляции. Лимиты QuickJS не применяются к React.
