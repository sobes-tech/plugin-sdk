# Диагностика

## Установка пакета

| Ошибка | Условие |
| --- | --- |
| `plugin_incompatible_api` | `apiVersion` отличается от числового `1` |
| `plugin_unsupported_slot` | Слот отсутствует в [поддерживаемом списке](ui-slots.md) |
| `plugin_unsupported_feature` / `plugin_unsupported_grant` | Заданы неподдерживаемые `requiredFeatures` или `grants` |
| Невалидный манифест | Ошибка ID, локализованных полей, повторное объявление или несовместимые renderer/slot/permissions |
| Превышение размера | Полный UTF-8 JSON больше 32 MiB |
| Несовпадение манифеста или SHA-256 | Данные каталога не соответствуют скачанному пакету |

Проверка типов не заменяет проверку пакета хостом. При установке из каталога проверяются точные байты файла и манифест.

## Регистрация интерфейса

Для отображения должны выполняться условия:

- установка включена и не имеет `PluginInstallation.error`;
- `views[].id` совпадает с ключом `renderPlugin` или `definePlugin.views`;
- слот поддерживается и имеет необходимое разрешение;
- для `renderer: "react"` присутствует UI-бандл.

`app.page` с `showInSidebar: false` не добавляется в навигацию; открывается через `app.openPage`. Видимость элементов оверлея дополнительно определяется настройками панели встречи.

React использует JSX runtime React. `@sobes-tech/plugin-sdk/ui` и JSX runtime SDK формируют сериализованные блоки для worker.

## Ошибки API

Поддержка метода определяется `api.capabilities`. Доступ определяется манифестом, подтверждёнными разрешениями и контекстом вызова. Изменение `manifest.ts` не меняет установленный пакет: требуется повторная сборка и установка.

| Ошибка или результат | Обработка |
| --- | --- |
| `plugin_api_failed` | Ошибка адаптера основного API; проверка параметров, прав и доступности ресурса |
| `plugin_api_timeout` | Результат не получен до дедлайна; выполненная серверная запись могла сохраниться |
| `PluginApiError` | Структурированная ошибка [API приложения](platform/README.md) |
| Конфликт `baseContentHash` | Требуется повторное чтение заметки и согласование изменения с её текущим содержимым |

Операции записи с неопределённым результатом нельзя считать отменёнными. Автоматический повтор создания объекта может создать дубликат. Основной API не предоставляет общий idempotency key; [CRUD ресурсов](platform/data.md) имеет отдельный контракт идемпотентности.

## Состояние и ошибки интерфейса

Необработанное исключение или отклонение promise останавливает соответствующий iframe. Повторный запуск создаёт новый экземпляр и API lease. Ожидаемые ошибки асинхронных вызовов обрабатываются в `catch`.

`useState` не является постоянным хранилищем. Данные сохраняются между экземплярами интерфейса только после записи через `storage` или `files`.

Повреждённый пакет, настройки или хранилище установки возвращают `enabled: false` и `PluginInstallation.error`. Невалидные настройки можно исправить повторным сохранением. Повторная установка того же digest не заменяет повреждённый immutable cache пакета.

## Файловые диалоги

`files.openJson` и `files.saveJson` требуют `files.userSelected`, React-интерфейс главного окна и активное пользовательское действие. Вызов после ожидания несвязанной асинхронной операции может утратить browser user activation.

Worker и оверлей не имеют доступа к этим диалогам. Одновременно разрешён один JSON-диалог. Второй вызов может вернуть `plugin_busy`. Отмена возвращает `null` для открытия и `false` для сохранения.

## Сеть и ресурсы

Прямой `fetch` из iframe блокируется CSP. `network.request` требует разрешения и подходящего имени хоста или маски в [`networkDomains`](network.md#разрешить-домены). Поддерживаются HTTPS GET/POST и текстовые UTF-8 ответы. Cookies Sobes и токен аккаунта не передаются. HTTP-ошибка может быть получена как обычный ответ со статусом.

Внешние скрипты, шрифты и изображения не загружаются. Ресурсы включаются в пакет как data URL.

## Каталог

Рефреш загружает метаданные, а не устанавливает пакет. Ошибки источников и записей передаются в `warningDetails`. Остальные доступные записи сохраняются.

Для воспроизведения ошибки необходимы ID и версия плагина, SHA-256 пакета, версия приложения, ОС и операция. Для ошибок вёрстки дополнительно нужны слот и размеры контейнера.
