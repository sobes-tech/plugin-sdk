# Platform API

[English](../../docs/en/platform/README.md) | [Русский](../../docs/ru/platform/README.md)

The public references cover [resource CRUD](../../docs/en/platform/data.md) and [local event streams](../../docs/en/platform/events.md). Import the client and types from `@sobes-tech/plugin-sdk`, or the React hook from `@sobes-tech/plugin-sdk/react`.

Справочники описывают [CRUD ресурсов](../../docs/ru/platform/data.md) и [локальные события](../../docs/ru/platform/events.md). Клиент и типы экспортируются из `@sobes-tech/plugin-sdk`, React-хук — из `@sobes-tech/plugin-sdk/react`.

Model HTTP requests use [createPluginFetch](../../docs/en/model-requests.md) and plugin-owned configuration. This resource API does not provide a model gateway.
